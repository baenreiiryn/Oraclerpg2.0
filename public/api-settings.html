Configurações da API

Escolha o provedor usado pelo OracleRPG ou conecte sua própria API. Chaves pessoais nunca são gravadas no navegador nem devolvidas ao frontend.

As chaves BYOK são enviadas somente por HTTPS para um endpoint autenticado, criptografadas antes de serem persistidas e isoladas por conta. O frontend recebe apenas o estado da configuração.
